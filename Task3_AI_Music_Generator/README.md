# AI Music Generator using LSTM

This project is an AI-powered Music Generator that creates new musical compositions using Deep Learning. The system is trained on MIDI music files and learns musical patterns such as notes, chords, and sequences using an LSTM (Long Short-Term Memory) neural network.

The project preprocesses MIDI datasets, extracts note sequences, converts them into numerical representations, and trains an LSTM model to predict the next note in a sequence. After training, the model generates new note patterns, which are converted back into MIDI format to create original music compositions.

## Features

* MIDI file preprocessing using Music21
* Note and chord extraction
* Sequence generation for training
* LSTM-based deep learning model
* AI-generated music creation
* MIDI file export for playback

## Technologies Used

* Python
* TensorFlow / Keras
* Music21
* NumPy
* Git & GitHub

## Workflow

1. Collect MIDI music data
2. Extract notes and chords
3. Convert notes into numerical sequences
4. Train an LSTM neural network
5. Generate new music sequences
6. Export generated music as a MIDI file
